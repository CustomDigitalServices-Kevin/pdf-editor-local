# Bundled handwriting fonts

Static TTF files copied unchanged from the [google/fonts](https://github.com/google/fonts) repository (2026-08-25). They are embedded as subsets in exported PDFs and loaded on demand on screen. None of them is a variable font (fontkit cannot subset `fvar` tables).
